# Cách mình học và đọc bài này

Mình đang học SQL cơ bản. Mình dùng dữ liệu Online Retail II để luyện tổng hợp và đọc kết quả bán hàng. Những phần ngoài mức cơ bản có AI hỗ trợ; mình không coi việc có code trong repository là đã tự làm thành thạo.

## Thứ tự đọc

1. Đọc README và `data/README.md` để biết nguồn, một dòng dữ liệu là gì và cách tải dữ liệu.
2. Mở `sql/02_thuc_hanh.sql`, đọc từng câu `SELECT`, điều kiện lọc và cách tính `SUM`, `COUNT` trước khi chạy.
3. Chọn một tháng, đối chiếu tổng tháng đó với output. Thử đổi điều kiện sang một quốc gia và giải thích kết quả.
4. Đọc `docs/METHOD.md` để hiểu vì sao chưa xóa dòng trùng và vì sao không so tháng 12/2011 như một tháng đủ dữ liệu.
5. Sau khi hiểu phần cơ bản, học thêm file 03. CTE và window functions là phần mở rộng được AI hỗ trợ, không bắt buộc để bắt đầu bài.

## Phạm vi hỗ trợ

- Mình cung cấp dữ liệu, bài thực hành và mục tiêu học SQL; notebook tham khảo chỉ giúp định hướng cách làm.
- AI hỗ trợ hoàn thiện bản portfolio, phần SQL nâng cao, script chuẩn bị dữ liệu và đối chiếu tự động.
- Kết quả kiểm tra của bộ file được ghi ở `VALIDATION.md`. Đây không phải bằng chứng mình đã tự chạy hoặc tự giải thích toàn bộ bài.
- Trước khi ghi dự án vào CV, mình cần tự chạy phần chính và giải thích được điều kiện lọc, cách cộng tiền và giới hạn dữ liệu.

## English

This is a beginner SQL learning project. The author supplies the data, existing exercise and learning direction. Advanced SQL, preparation scripts and automated validation are AI-assisted. Recorded checks apply to the delivered files; they do not establish independent mastery. Start with basic queries in file 02, reconcile one monthly result, then study file 03 as an optional extension.
